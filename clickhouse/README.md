# Лабораторная работа №2: ClickHouse для e-commerce данных

## Описание
Аналитическая система для анализа каталога товаров и пользовательских событий интернет-магазина на основе ClickHouse.

ПЕРЕД НАЧАЛОМ РАБОТЫ:
положить ```10ozon.csv``` в data/import

Билд и поднятие докера
```
cd clickhouse
docker-compose build
docker-compose up -d
```

Нагрузочное тестирование
```
cd clickhouse
pip install pandas requests
python load_test.py
```

# Проверка статуса
docker-compose ps

# Доступ к сервисам:
# - ClickHouse HTTP: http://localhost:8123
# - ClickHouse native: localhost:9000
# - Grafana: http://localhost:3001 (admin/admin)
# - Prometheus: http://localhost:9091

Основные запросы находятся в queries.sql:

Топ-20 категорий по количеству товаров

Топ-30 брендов по количеству товаров

Среднее количество товаров по брендам в категориях

Анализ товаров без пользовательских событий

Материализованные представления
catalog_by_category_mv - агрегаты по категориям

catalog_by_brand_mv - агрегаты по брендам

catalog_coverage_mv - анализ покрытия каталога событиями

Мониторинг
Grafana дашборды:

Технический мониторинг (ID: 13606) - метрики ClickHouse

Бизнес-аналитика - топ категорий, брендов, активность по устройствам
